# حيّاك — دعوات المناسبات وتأكيد الحضور

تطبيق ويب بواجهة عربية للسوق السعودي:

1. المنظّم يسجّل ويُنشئ مناسبة (زواج، خطوبة، تخرج…) ويختار لها قالباً من 10 قوالب.
2. يضيف المعازيم (اسم ورقم)، فيُنشأ لكل ضيف **بطاقة دعوة خاصة به عليها رمز QR** ورابط دعوة.
3. يضغط «إرسال الدعوات» فتصل كل ضيف **رسالة واتساب** بصورة البطاقة ونص الدعوة وثلاثة أزرار: **قبول الدعوة / الاعتذار عن الدعوة / موقع المناسبة**. ضغطة الضيف على الزر تحدّث حالته في التطبيق مباشرة.
4. **قبل المناسبة بيوم** (الساعة 10 صباحاً بتوقيت الرياض افتراضياً) يصل تذكير تلقائي لمن لم يعتذر، بأزرار «أؤكد حضوري / أعتذر / الموقع».
5. المنظّم يتابع لوحة الحضور لحظياً (وهل وصلت الرسالة وهل قُرئت)، وينزّل القائمة كملف Excel.

الضيف الذي يقبل الدعوة يفتح رابطه (بدون تنزيل أي شيء) ليضيف عدد المرافقين، ويرى **رمز QR الخاص به**.

## التشغيل

يحتاج Node.js **22.13 أو أحدث**. لا قواعد بيانات خارجية (SQLite مدمجة).

**ويندوز:** انقر مرتين على `start.bat` (إن لم يكن Node مثبتاً ضع مجلد Node المحمول باسم `node` بجانب الملف).
**ماك / لينكس:** `./start.sh`

أو يدوياً:

```bash
cp .env.example .env     # عدّل القيم
npm install
npm start                # http://localhost:3000
npm test                 # الاختبارات (27 اختباراً)
```

> **ويندوز يمنع `start.bat`؟** (رسالة Smart App Control) افتح الفولدر، اكتب `cmd` في شريط العنوان واضغط Enter، ثم نفّذ: `node\node.exe --disable-warning=ExperimentalWarning server.js`

## أرقام الجوال (أي دولة)

التسجيل والدخول وإضافة المعازيم تقبل أرقام أي دولة: تختار الدولة من القائمة (تُحفظ لآخر مرة) وتكتب الرقم كما تعرفه (`0501234567` أو `01012345678`)، أو تكتب الرقم دولياً مع `+` (`+44 7911 123456`) فيُؤخذ كما هو. في قائمة المعازيم تقدر تخلط أكثر من دولة. الدولة الافتراضية السعودية، وتتغير بـ `DEFAULT_COUNTRY_CODE` في `.env`.

## الوضع التجريبي (لعرض التطبيق على العميل)

في الإعداد الافتراضي (`WHATSAPP_MODE=console`) لا تُرسل أي رسالة فعلية. تظهر الرسالة في «سجل الرسائل» داخل كل مناسبة **بشكل رسالة واتساب** (صورة البطاقة، النص، الأزرار الثلاثة)، وتقدر تضغط على أزرارها لتجرّب كيف يرد الضيف، فتتغير حالته في القائمة. هذا مناسب جداً لعرض الفكرة على العميل قبل ربط واتساب الحقيقي.

## الإرسال الفعلي عبر واتساب (Meta WhatsApp Cloud API)

> **تنبيه صريح:** ربط Meta مكتوب حسب صيغة الـ API المعروفة ومغطى باختبارات تحاكي ردود Meta، لكنه **لم يُجرَّب على حساب واتساب للأعمال حقيقي** (لا يوجد حساب لدينا). متوقع أن تحتاج لتعديل بسيط عند أول تجربة فعلية، وأي رفض من Meta يظهر في التطبيق بنص الخطأ نفسه.

### ما تحتاجه من العميل

1. حساب **Meta Business** موثَّق (Business Verification) وتطبيق في [developers.facebook.com](https://developers.facebook.com) مع منتج WhatsApp.
2. **رقم جوال مخصص** لواتساب للأعمال (لا يكون مسجلاً في تطبيق واتساب العادي).
3. **رابط عام https** للتطبيق، لسببين: تحميل Meta لصورة البطاقة، واستقبال ضغطات الأزرار (Webhook). يعني لا بد من استضافة التطبيق على سيرفر (VPS أو Railway/Render…) وليس على جهاز شخصي.
4. **رسوم الرسائل:** تُحتسب من Meta على كل رسالة قالب مبادَرة. راجع تسعير السعودية الحالي في لوحة Meta.

### الخطوات

**1) أنشئ قالبين في WhatsApp Manager** (قوالب الرسائل ← إنشاء قالب)، التصنيف **Marketing**، اللغة **العربية (ar)**:

| | القالب الأول | القالب الثاني |
|---|---|---|
| الاسم | `hayyak_invite` | `hayyak_reminder` |
| الترويسة | صورة (ارفع أي صورة نموذجية) | صورة (نموذجية) |
| الأزرار | 3 أزرار «رد سريع»: قبول الدعوة، الاعتذار عن الدعوة، موقع المناسبة | 3 أزرار «رد سريع»: أؤكد حضوري، أعتذر عن الحضور، موقع المناسبة |

نص القالب الأول (الجسم) بالضبط:

```
السلام عليكم ورحمة الله وبركاته

*{{1}}*

بكل الود والمحبة تتشرف
*{{2}}*

بدعوتكم لحضور {{3}}
*{{4}}*

وذلك:-
🗓️| {{5}}
📍| {{6}}

📌 يسعدنا تأكيد حضوركم وذلك بالضغط على أيقونة قبول الدعوة بالرسالة أدناه
```

أمثلة المتغيرات التي تطلبها Meta: `{{1}}` المكرمة : ريم القصيبي · `{{2}}` حنان الجميعه و حصه العبدالعظيم · `{{3}}` حفل زفاف · `{{4}}` فهد و دانة · `{{5}}` يوم الجمعة 20.11.2026 · `{{6}}` فندق فيرست جراند

نص القالب الثاني (الجسم) بالضبط:

```
السلام عليكم ورحمة الله وبركاته

*{{1}}*

نذكّركم بدعوتكم لحضور {{2}}
*{{3}}*

وذلك {{4}}
📍| {{5}}

📌 نأمل تأكيد حضوركم مرة أخرى بالضغط على أحد الأزرار أدناه
```

أمثلة المتغيرات: `{{1}}` المكرمة : ريم القصيبي · `{{2}}` حفل زفاف · `{{3}}` فهد و دانة · `{{4}}` غداً يوم الجمعة 20.11.2026 الساعة 8:30 م · `{{5}}` فندق فيرست جراند

> سبب السطر الأول «السلام عليكم…»: Meta ترفض أي قالب يبدأ بمتغير. والنص لازم يطابق ما في التطبيق حرفاً بحرف، وإلا ترفض Meta الإرسال.
> انتظر اعتماد القالبين (دقائق إلى ساعات).

**2) اضبط ملف `.env`:**

```
INVITE_CHANNEL=whatsapp
WHATSAPP_MODE=cloud
PUBLIC_BASE_URL=https://موقعك.com
WHATSAPP_TOKEN=...            # Access Token دائم (System User) من Meta
WHATSAPP_PHONE_ID=...         # Phone number ID
WHATSAPP_APP_SECRET=...       # App Secret للتطبيق
WHATSAPP_VERIFY_TOKEN=...     # كلمة سر من اختيارك
WHATSAPP_TEMPLATE_INVITE=hayyak_invite
WHATSAPP_TEMPLATE_REMINDER=hayyak_reminder
```

**3) اضبط الـ Webhook** في Meta (WhatsApp ← Configuration):
- Callback URL: `https://موقعك.com/webhooks/whatsapp`
- Verify token: نفس `WHATSAPP_VERIFY_TOKEN`
- اشترك في الحقل **messages** (يشمل ضغطات الأزرار وحالات التسليم والقراءة).

**4) جرّب** بمناسبة صغيرة ورقم جوالك أنت.

### كيف يعمل
- الصورة في أعلى الرسالة تُولَّد للضيف من قالب المناسبة، وتُخدم من `/card/<رمز الضيف>.png`.
- ضغطة «قبول الدعوة» تسجّل القبول وتُرسَل للضيف رسالة شكر فيها رابط لإضافة المرافقين؛ «الاعتذار» تسجّل الاعتذار؛ «موقع المناسبة» ترد برابط الخرائط والمكان ولا تغيّر الحالة. الردود الفورية على الأزرار مجانية (داخل نافذة الـ 24 ساعة).
- اللقب (المكرم / المكرمة / بدون) يُختار عند إضافة المعازيم ويُعدّل لكل ضيف من «خيارات ← تعديل».
- Meta تتحقق من توقيع كل طلب Webhook، وأي طلب بدون توقيع صحيح يُرفض.

## رمز QR

لكل ضيف رمز يحمل رابط دعوته الخاص: يظهر على بطاقته (في واتساب)، وفي صفحة دعوته بعد القبول، ويُنزَّل من التطبيق («خيارات ← بطاقة الدعوة و QR»). حالياً الرمز يفتح صفحة الدعوة؛ **ماسح الدخول عند باب القاعة** (مسح الرمز وتسجيل الحضور الفعلي) غير مبني بعد، ويمكن إضافته.

## الإرسال بـ SMS (بديل)

`INVITE_CHANNEL=sms` يرجع للرسالة النصية التي فيها رابط الدعوة. المدعوم **تقنيات (Taqnyat)**:

```
SMS_PROVIDER=taqnyat
SMS_SENDER=اسم_المرسل_المعتمد
SMS_API_KEY=مفتاح_الـAPI
```

- اسم المرسِل (Sender ID) لازم يكون معتمداً قبل الإرسال، والاعتماد يأخذ وقتاً.
- الرسالة العربية تُحسب بـ 70 حرفاً للجزء الواحد.
- لإضافة مزود آخر أضف دالة في `src/sms.js` داخل الكائن `providers`.

## النشر

- لازم HTTPS، وضع عنوان موقعك في `PUBLIC_BASE_URL`.
- يحتاج **قرصاً دائماً** لمجلد `data/` (أو غيّر `DATA_DIR`)، ويعمل كعملية واحدة دائمة لأن مجدول التذكير داخله.
- شغّله خلف خدمة تعيد تشغيله تلقائياً (systemd أو pm2 أو الاستضافة نفسها).
- بعد إنشاء حساب العميل اجعل `ALLOW_REGISTRATION=false`.
- انسخ ملف `data/hayyak.db` دورياً كنسخة احتياطية.
- الخطوط المستخدمة في صورة البطاقة داخل `assets/fonts` (رخصة OFL).

## كيف يعمل التذكير

المجدول يفحص كل دقيقة. لكل مناسبة قادمة، عند حلول **الساعة `REMINDER_HOUR` من اليوم السابق** (بتوقيت الرياض) يرسل تذكيراً لكل ضيف وصلته الدعوة ولم يعتذر. إذا أُرسلت الدعوات بعد هذا الموعد، يصل التذكير بعد 12 ساعة من الدعوة. تعديل موعد المناسبة يعيد جدولة التذكير. زر «إرسال تذكير الآن» متاح يدوياً.

## إضافة قالب

عرّف القالب في `src/theme-data.js` (ألوان، خط، زخرفة) وأضف اسمه في `src/templates.js`، ثم شغّل `node tools/build-themes.js`. يظهر في موقع الدعوة وفي صورة البطاقة معاً.

## هيكل المشروع

```
server.js          المسارات (API) والـ Webhook والحماية
src/               قاعدة البيانات، الأرقام، الرسائل، واتساب، البطاقة، الإرسال، المجدول
public/            واجهة المنظّم (app.js) وصفحة الضيف (invite.js)
assets/fonts       خطوط صورة البطاقة
test/              اختبارات التدفق الكامل وواتساب
```
