# حيّاك — دعوات المناسبات وتأكيد الحضور

تطبيق ويب بواجهة عربية للسوق السعودي:

1. المنظّم يسجّل ويُنشئ مناسبة (زواج، خطوبة، تخرج…) ويختار لها قالباً من 10 قوالب.
2. يضيف المعازيم (اسم ورقم)، فيُنشأ لكل ضيف **بطاقة دعوة خاصة به عليها رمز QR** ورابط دعوة.
3. يضغط «إرسال الدعوات» فتصل كل ضيف **رسالة واتساب** بصورة البطاقة ونص الدعوة، ومعها **استفتاء بخيارين: قبول الدعوة / الاعتذار عن الدعوة**. اختيار الضيف أحد الخيارين يحدّث حالته في التطبيق مباشرة.
4. **قبل المناسبة بيوم** (الساعة 10 صباحاً بتوقيت الرياض افتراضياً) يصل تذكير تلقائي لمن لم يعتذر، باستفتاء «أؤكد حضوري / أعتذر عن الحضور».
5. المنظّم يتابع لوحة الحضور لحظياً (وهل وصلت الرسالة وهل قُرئت)، وينزّل القائمة كملف Excel.

الضيف الذي يقبل الدعوة يفتح رابطه (بدون تنزيل أي شيء) ليضيف عدد المرافقين، ويرى **رمز QR الخاص به**.

## التشغيل

يحتاج Node.js **22.13 أو أحدث**. لا قواعد بيانات خارجية (SQLite مدمجة).

**ويندوز:** انقر مرتين على `start.bat` (إن لم يكن Node مثبتاً ضع مجلد Node المحمول باسم `node` بجانب الملف).
**ماك / لينكس:** `./start.sh`

أو يدوياً:

```bash
cp .env.example .env     # عدّل القيم
npm install
npm start                # http://localhost:3000
npm test                 # الاختبارات (29 اختباراً)
```

> **ويندوز يمنع `start.bat`؟** (رسالة Smart App Control) افتح الفولدر، اكتب `cmd` في شريط العنوان واضغط Enter، ثم نفّذ: `node\node.exe --disable-warning=ExperimentalWarning server.js`

## أرقام الجوال (أي دولة)

التسجيل والدخول وإضافة المعازيم تقبل أرقام أي دولة: تختار الدولة من القائمة (تُحفظ لآخر مرة) وتكتب الرقم كما تعرفه (`0501234567` أو `01012345678`)، أو تكتب الرقم دولياً مع `+` (`+44 7911 123456`) فيُؤخذ كما هو. في قائمة المعازيم تقدر تخلط أكثر من دولة. الدولة الافتراضية السعودية، وتتغير بـ `DEFAULT_COUNTRY_CODE` في `.env`.

## الوضع التجريبي (لعرض التطبيق على العميل)

في الإعداد الافتراضي (`WHATSAPP_MODE=console`) لا تُرسل أي رسالة فعلية. تظهر الرسالة في «سجل الرسائل» داخل كل مناسبة **بشكل رسالة واتساب** (صورة البطاقة، النص، خيارا الاستفتاء)، وتقدر تضغط على الخيارين لتجرّب كيف يرد الضيف، فتتغير حالته في القائمة. هذا مناسب جداً لعرض الفكرة على العميل قبل ربط واتساب الحقيقي.

## الإرسال الفعلي عبر واتساب (WAHA — محرك WEBJS)

> **تنبيه:** WAHA يعمل عبر WhatsApp Web (غير رسمي). استخدم **رقمًا مخصصًا** للدعوات، وسخّنه تدريجيًا، ولا ترسل كميات كبيرة فجأة — احتمال الحظر وارد. الرسائل والردود مجانية (لا رسوم Meta).

### الأزرار مقابل الاستفتاء

أزرار WAHA التفاعلية (`sendButtons`) **متوقفة حاليًا** ومعلَّمة `deprecated` في وثائق WAHA وOpenAPI. البديل المدعوم رسميًا على WEBJS هو **الاستفتاء (`sendPoll`)**، ولذلك:

- تصل صورة البطاقة + نص الدعوة في رسالة (`sendImage`).
- يليها استفتاء بخيارين: **قبول الدعوة / الاعتذار عن الدعوة** (وفي التذكير: **أؤكد حضوري / أعتذر عن الحضور**).
- تصويت الضيف يصل عبر Webhook (`poll.vote`) ويُسجَّل في قاعدة البيانات والداشبورد.
- نص الرسالة يحمل دائمًا رابط الرد `/i/<token>` كشبكة أمان، ولو فشل إرسال الاستفتاء يُرسَل النص تلقائيًا (`sendText`).

### 1) شغّل WAHA (Docker)

```bash
sudo docker run -d --name waha --restart unless-stopped \
  -p 127.0.0.1:3006:3000 \
  -e WHATSAPP_DEFAULT_ENGINE=WEBJS \
  -e WHATSAPP_API_KEY=ضع-مفتاحًا-طويلًا \
  -e WHATSAPP_HOOK_URL=http://172.17.0.1:3005/webhooks/waha \
  -e WHATSAPP_HOOK_EVENTS=message,poll.vote,message.ack,session.status \
  -e WHATSAPP_HOOK_HMAC_KEY=ضع-سرًا-آخر \
  -e WHATSAPP_HOOK_RETRIES_ATTEMPTS=10 \
  -v "$PWD/waha-sessions:/app/.sessions" \
  devlikeapro/waha:latest
```

- `127.0.0.1:3006` يعني أن WAHA غير مكشوف للإنترنت.
- `WHATSAPP_HOOK_URL` يشير إلى التطبيق من داخل الحاوية؛ على لينكس استخدم `172.17.0.1` وليس `localhost`.
- مجلد `waha-sessions` يحفظ الجلسة بعد إعادة التشغيل.

### 2) اضبط `.env`

```
INVITE_CHANNEL=whatsapp
WHATSAPP_MODE=waha
PUBLIC_BASE_URL=https://dawaa.whoisthare.com
WAHA_BASE_URL=http://127.0.0.1:3006
WAHA_API_KEY=نفس-المفتاح-السابق
WAHA_SESSION=default
WAHA_WEBHOOK_HMAC_KEY=نفس-السر-السابق
```

### 3) امسح QR

افتح `http://127.0.0.1:3006/dashboard` من جهازك (عبر نفق SSH إن لزم: `ssh -L 3006:127.0.0.1:3006 hema@السيرفر`)، ثم امسح رمز QR من جوال الرقم المخصص. انتظر حتى تصبح الحالة `WORKING` — تظهر أيضًا كشارة «واتساب متصل» في الداشبورد.

### كيف يعمل

- **الإرسال:** `sendImage` بصورة البطاقة (base64 من `renderCard`، بلا حاجة لرابط عام للصورة) + `sendPoll` بالخيارين. كل رسالة تُسجَّل في `outbox` مع معرّف الصورة ومعرّف الاستفتاء.
- **الاستقبال:** WAHA يرسل الأحداث إلى `/webhooks/waha` موقَّعة بـ HMAC-SHA512 (`X-Webhook-Hmac`). يُرفض أي طلب بدون توقيع صحيح، ويُمنع تكرار المعالجة عبر جدول `webhook_events`.
- **`poll.vote`:** يُطابَق معرّف الاستفتاء بصف `outbox.poll_ext_id` ثم يُنادى `handleButton()` — نفس مسار صفحة الدعوة — فيتحدث `guests.status` و`responded_at` وتظهر فقاعة «رد وارد» في سجل الرسائل، ويُرسل للضيف رد شكر.
- **رسالة نصية:** «قبول/أعتذر/1/2» تعمل كبديل، وأي نص آخر يُسجَّل كرسالة واردة دون تغيير الحالة.
- **`message.ack`:** يحدّث حالة التسليم/القراءة (`sent/delivered/read`).
- **`session.status`:** يحدّث شارة الاتصال في الداشبورد.

### ملاحظات تشغيل

- الرقم المخصص يُفضَّل أن يكون **رقمًا جديدًا غير مستخدم** في واتساب عادي، ويُسخَّن تدريجيًا (warm-up).
- التطبيق يضع فاصلًا 4–7 ثوانٍ بين الرسائل (`WAHA_SEND_DELAY_MS` + `WAHA_SEND_JITTER_MS`).
- لو توقفت WAHA أو الجلسة، تظهر الحالة في الداشبورد وتفشل الرسائل بسبب واضح بدل التعليق.

## رمز QR

لكل ضيف رمز يحمل رابط دعوته الخاص: يظهر على بطاقته (في واتساب)، وفي صفحة دعوته بعد القبول، ويُنزَّل من التطبيق («خيارات ← بطاقة الدعوة و QR»). حالياً الرمز يفتح صفحة الدعوة؛ **ماسح الدخول عند باب القاعة** (مسح الرمز وتسجيل الحضور الفعلي) غير مبني بعد، ويمكن إضافته.

## الإرسال بـ SMS (بديل)

`INVITE_CHANNEL=sms` يرجع للرسالة النصية التي فيها رابط الدعوة. المدعوم **تقنيات (Taqnyat)**:

```
SMS_PROVIDER=taqnyat
SMS_SENDER=اسم_المرسل_المعتمد
SMS_API_KEY=مفتاح_الـAPI
```

- اسم المرسِل (Sender ID) لازم يكون معتمداً قبل الإرسال، والاعتماد يأخذ وقتاً.
- الرسالة العربية تُحسب بـ 70 حرفاً للجزء الواحد.
- لإضافة مزود آخر أضف دالة في `src/sms.js` داخل الكائن `providers`.

## النشر

- لازم HTTPS، وضع عنوان موقعك في `PUBLIC_BASE_URL`.
- يحتاج **قرصاً دائماً** لمجلد `data/` (أو غيّر `DATA_DIR`)، ويعمل كعملية واحدة دائمة لأن مجدول التذكير داخله.
- شغّله خلف خدمة تعيد تشغيله تلقائياً (systemd أو pm2 أو الاستضافة نفسها).
- بعد إنشاء حساب العميل اجعل `ALLOW_REGISTRATION=false`.
- انسخ ملف `data/hayyak.db` دورياً كنسخة احتياطية.
- الخطوط المستخدمة في صورة البطاقة داخل `assets/fonts` (رخصة OFL).

## كيف يعمل التذكير

المجدول يفحص كل دقيقة. لكل مناسبة قادمة، عند حلول **الساعة `REMINDER_HOUR` من اليوم السابق** (بتوقيت الرياض) يرسل تذكيراً لكل ضيف وصلته الدعوة ولم يعتذر. إذا أُرسلت الدعوات بعد هذا الموعد، يصل التذكير بعد 12 ساعة من الدعوة. تعديل موعد المناسبة يعيد جدولة التذكير. زر «إرسال تذكير الآن» متاح يدوياً.

## إضافة قالب

عرّف القالب في `src/theme-data.js` (ألوان، خط، زخرفة) وأضف اسمه في `src/templates.js`، ثم شغّل `node tools/build-themes.js`. يظهر في موقع الدعوة وفي صورة البطاقة معاً.

## هيكل المشروع

```
server.js          المسارات (API) والـ Webhook والحماية
src/               قاعدة البيانات، الأرقام، الرسائل، واتساب، البطاقة، الإرسال، المجدول
public/            واجهة المنظّم (app.js) وصفحة الضيف (invite.js)
assets/fonts       خطوط صورة البطاقة
test/              اختبارات التدفق الكامل وواتساب
```
